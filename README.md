# Ladeplanung Cupra Born

Zeigt während der Fahrt die Ladepunkte voraus auf einer Stammstrecke — Streckenkilometer, Höhenanstieg, Ladeleistung, Notiz.

- `index.html`, `manifest.json`, `routes.json` — die PWA, veröffentlicht über GitHub Pages
- `apps-script/` — an das Google Sheet gebundenes Script (per `clasp`), erzeugt `routes.json`

Grundlage: Umsetzungsbrief v5.0, Stufe 1.
