# Ladeplanung Cupra Born

Zeigt während der Fahrt die Ladepunkte voraus auf einer Stammstrecke — Streckenkilometer, Höhenanstieg, Akku-Prognose, Leistung, Lage und Notiz.

**App:** https://obitusde.github.io/ladeplanung/

- `index.html`, `manifest.json` — die PWA (GitHub Pages)
- `routes.json`, `linien/`, `modell.json` — Daten, vom Apps Script erzeugt
- `apps-script/` — an das Google Sheet gebundenes Script (clasp) mit Web-App-Formularen
- `tests/` — Node-Tests und Werkzeuge
- `docs/Umsetzungsbrief_v5.0.md` — ursprünglicher Auftrag

**Vollständiger Projektstand, Entscheidungen und Arbeitsweise: [`CLAUDE.md`](CLAUDE.md).**
